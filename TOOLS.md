| Tool | Runs on | Description | Inputs | Outputs |
|---|---|---|---|---|
| `snapshot` | laptop | Fetch a fresh image from the robot camera. The image is attached to your next turn. | none | {note}; the new image is attached to your next turn |
| `goto_pose` | pi | Navigate (Nav2) to a pose in the map frame. x,y metres, yaw radians. | `x`: number<br>`y`: number<br>`yaw`?: number<br>`frame`?: 'map' | {pose} when the goal is reached, or error |
| `move` | pi | Short relative motion: drive distance_m forward (negative = back) and/or turn turn_deg (positive = left). Max 1.0 m / 180 deg per call. | `distance_m`?: number (min -1.0, max 1.0)<br>`turn_deg`?: number (min -180, max 180) | {requested/done motion} |
| `look` | pi | Point the camera head. tilt_deg absolute (-80..80). pan: {mode:'relative', deg} or {mode:'home'} (home needs pan_home_deg configured). Pan has no encoder, so the angle is an estimate. | `tilt_deg`?: number (min -80, max 80)<br>`pan`?: {mode: 'relative' / 'home', deg: number (min -180, max 180)}<br>`settle_ms`?: integer (min 0, max 3000) | {head: {tilt_deg, pan_deg_est}, pan_confidence} |
| `stop` | pi | Soft stop: cancel navigation and stop moving. Not latched. | none | {stopped: true} |
| `estop` | estop | EMERGENCY STOP. Latches on the robot. You can trigger it but you can NEVER clear it; only Amey can, on the dashboard. | `reason`?: string | {estop: 'sent'} (latched) |
| `detect` | pi | Object detection with the Pi YOLO node. Returns labelled boxes for the given labels. | `labels`: array of string<br>`window_ms`?: integer (min 200, max 5000)<br>`min_conf`?: number (min 0, max 1)<br>`verify`?: boolean | {detections: [{label, conf, bbox}]} |
| `map` | pi | Mapping: action 'status' \| 'save' (name) \| 'semantic' (labels) \| 'coverage' \| 'explore' (enable true/false, max_s). Amey allows you to explore and save maps without asking. | `action`: 'status' / 'save' / 'semantic' / 'coverage' / 'explore'<br>`enable`?: boolean<br>`max_s`?: integer (min 10, max 1800)<br>`name`?: string<br>`labels`?: array of string | {map: status / saved path / semantic labels / coverage / explore state} |
| `get_status` | pi | Robot status: pose, head, E-STOP latch, safety_blocked, nav state. | none | {pose: {x,y,yaw}, head, estop: {latched}, safety_blocked, nav} |
| `ask_user` | laptop | Ask Amey a question in the GUI and stop the run until he answers with a new command. | `question`: string | run stops until Amey answers |
| `finish` | laptop | End the task with a final answer. | `answer`: string | task ends with your answer |
| `describe_scene` | laptop | Look at ONE fresh camera image. With 'target', say whether that object is visible and give its bounding box in pixels. | `target`?: string | {found: bool\|null, description: str, bbox: [x1,y1,x2,y2] px\|null, image: {width,height}} |
| `feed` | laptop | Camera feed at an interval: take a frame every interval_s for up to max_s, describe each; stops early if 'goal' is seen. Use to search a region. Always say why in 'purpose'; it is echoed back so you can judge if the task is done. | `purpose`: string<br>`goal`?: string<br>`interval_s`?: number (min 0.5, max 30)<br>`max_s`?: number (min 1, max 600) | {purpose: str (why the feed was run), met: bool, frames: int, last: {found, description, bbox}, history: [descriptions], reason: goal\|timeout} |
| `watch_for` | laptop | Describe the scene continuously, one frame per second, until 'goal' is seen or max_s passes. | `goal`: string<br>`max_s`?: number (min 1, max 600) | {met: bool, frames: int, last: {found, description, bbox}, reason: goal\|timeout} |
| `start_exploring` | laptop | Turn on frontier exploration (it keeps going by itself). Optional condition: until_seen (stop when that object is seen) and/or max_s. | `max_s`?: integer (min 10, max 1800)<br>`until_seen`?: string<br>`check_interval_s`?: number (min 1, max 30) | {exploring: bool, stopped_because: seen\|timeout\|null, last: {...}\|null} (without until_seen it returns at once while exploration carries on) |
| `stop_exploring` | laptop | Stop frontier exploration. | none | {exploring: false} |
| `save_map` | laptop | Save the current map (to ~/maps/<name>). | `name`?: string | {saved: name, map: robot reply} |
| `save_location` | laptop | Save the robot's current x, y, yaw as a named location (overwrites the same name). | `name`: string<br>`note`?: string | {saved: {name, x, y, yaw, note}} |
| `note_location` | laptop | Remember something special about a location (named, or the current spot if no name; current spot is saved as 'spot-N'). | `name`?: string<br>`note`: string | {saved: {name, x, y, yaw, note}} |
| `recall_location` | laptop | Navigate to a saved named location. | `name`: string | {location: {...}, nav: goto_pose reply} |
| `list_locations` | laptop | List saved locations with poses and notes. | none | {locations: [{name, x, y, yaw, note}]} |
| `delete_location` | laptop | Delete a saved location. | `name`: string | {deleted: name} |
| `return_home` | laptop | Navigate to the saved location 'home'. | none | {location: {...}, nav: goto_pose reply} |
| `wait` | laptop | Pause for seconds (cancellable). | `seconds`: number (min 0, max 300) | {waited_s: number} |
| `scan_area` | laptop | Sweep the view: pan the head (use='head') or rotate the body (use='body') through angles_deg, checking each view for 'target'. Stops at the first hit. | `target`: string<br>`use`?: 'head' / 'body'<br>`angles_deg`?: array of number (min -180, max 180) | {found: bool, at_deg: number\|null, views: [{deg, found, description, bbox}]} |
| `go_to_object` | laptop | Approach a visible object: turn toward its bounding box and drive in short hops until it fills enough of the view or stop_m budget ends. | `target`: string<br>`max_m`?: number (min 0.1, max 5) | {reached: bool, driven_m: number, reason: close\|lost\|budget, last: {found, description, bbox}} |
| `follow` | laptop | Follow an object: keep turning toward it and closing distance until max_s; stops if it is lost. | `target`: string<br>`max_s`?: number (min 1, max 600) | {followed_s: number, reason: lost\|timeout, last: {...}} |
| `set_speed` | pi | Set the navigation speed limit in m/s (clamped 0.05..0.5). | `max_mps`: number (min 0.05, max 0.5) | {max_mps: number} |
| `record_video` | laptop | Start or stop recording camera frames to disk. | `action`: 'start' / 'stop'<br>`fps`?: number (min 0.5, max 10) | {recording: bool, dir: path, frames: int} |
